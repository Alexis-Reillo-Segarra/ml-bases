# ml-bases

Fundamentos de Machine Learning trabajados con notebooks de Jupyter.

## Estructura

| Carpeta | Contenido |
|---|---|
| `01-estadistica/` | Estadística descriptiva e inferencial |
| `02-matematicas/` | Álgebra lineal, cálculo y optimización |
| `03-regresion/` | Modelos de regresión |
| `data/` | Datasets locales (ignorados por git) |

## Requisitos

- Python 3.14
- [uv](https://docs.astral.sh/uv/)

## Instalación

```bash
uv sync
```

## Uso

```bash
uv run jupyter lab
```

## Dependencias principales

numpy, pandas, scipy, statsmodels, scikit-learn, matplotlib, seaborn, jupyter.
